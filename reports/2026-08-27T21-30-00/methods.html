Method

Unsupervised adaptation, then transfer

Every transfer method starts from a Stage A base fitted on unpaired target text. The raw-text and structured-prior arms use matched target completions and differ only in whether the prompt exposes the supplied audience, profile, community, thread, keyword, dimension and engagement information.

Unsupervised scale ladder

The 1,000-record samples are deterministic nested scale controls. The coarse-to-fine arm partitions the primary training records into disjoint platform and audience halves, so its two stages have exactly the primary arm's completion-token exposure.

Steering decomposition

Platform and train-only audience contrasts were recomputed in each frozen checkpoint. Per-layer Gram–Schmidt residuals prevent the audience direction from duplicating the platform direction; pair singular values and projections remain in each steering artifact.

Every selected coefficient is zero

Selection returned the null intervention for every variant in this build, so each steering column is an unsteered baseline. See Limitations.

Every steering number elsewhere in this report is an 8B number. Section 4.5 of the plan adds a scale arm that runs the identical difference-in-means construction on NDIF-hosted Llama-3.1-70B-Instruct, whose residual stream is exposed for read and write. That arm has produced no scored output, and nothing in this report rests on it.

One artifact is fitted: target_lm on meta-llama/Llama-3.1-70B-Instruct, hidden size 8192, from a corpus at /Users/davidchan/Projects/vectorial/data.

Why there is nothing to report

  • The layer-and-alpha sweep has not run, and the plan forbids scoring the artifact until it does. A spot check at layer 40, alpha 0.5 left the output structurally Reddit-like but code-switching into Spanish and German.
  • The fitted artifact reads a different corpus from the local steering column it is meant to contrast against, so as fitted it varies corpus and scale at once. A valid contrast needs a refit on the same corpus.
  • sweep_steering had no remote path until this build; it selected the local generator, which would have loaded a 70B model against 4,096-wide local vectors rather than the 8,192-wide remote stream.
  • Remote columns are never pooled with the local 4-bit columns: NDIF serves its own precision, so the study's quantisation constant does not cover this arm. It is a scale contrast against the local steering column and nothing else.
